# Contribuindo com o NascIA

Obrigado pelo interesse em contribuir! Este é um projeto de portfólio em desenvolvimento contínuo, e sugestões são bem-vindas.

## Como contribuir

1. Faça um fork deste repositório
2. Crie uma branch para sua alteração:
   ```
   git checkout -b feature/nome-da-sua-melhoria
   ```
3. Faça suas alterações e commit:
   ```
   git commit -m "feat: descreve a alteração feita"
   ```
4. Envie para o seu fork:
   ```
   git push origin feature/nome-da-sua-melhoria
   ```
5. Abra um Pull Request explicando o que foi alterado e por quê

## Boas práticas de commit

Este projeto segue o padrão [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` para novas funcionalidades
- `fix:` para correções de bugs
- `docs:` para alterações de documentação
- `refactor:` para refatorações sem mudança de comportamento
- `chore:` para tarefas de manutenção

## Reportando problemas

Se encontrar um bug ou tiver uma sugestão, abra uma [Issue](../../issues) descrevendo:
- O que aconteceu (ou o que você gostaria que existisse)
- Passos para reproduzir (se for um bug)
- Comportamento esperado

## Dados sensíveis

**Nunca** inclua boletos reais, credenciais, tokens de API ou IDs de planilhas em Pull Requests. Use sempre os placeholders já presentes no projeto (ex: `.env.example`).

## Código de conduta

Seja respeitoso e construtivo nas interações. Este é um projeto de aprendizado aberto a colaboração.
